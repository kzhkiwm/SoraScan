## 📖 概要

**SoraScan** は、日向坂46のCD（シングル・アルバム）に封入されている「スペシャル抽選応募シリアルナンバー」を、スマートフォンのカメラや写真から瞬時に読み取り（OCR文字認識 & QRコード自動検知）、重複チェック・ステータス管理・一括コピー・CSV出力までをシームレスに行うためのWebアプリケーション（PWA）です。

CDを何十枚〜何百枚と開封する熱心なおひさま（ファン）の**「シリアル手入力の手間」**や、**「0（ゼロ）とO（オー）、1（イチ）とI（アイ）の打ち間違い」**のストレスを解消し、スムーズかつ確実な応募作業をサポートします。

## ✨ 主な機能

### 1. 📷 高精度OCR ＆ 超高速QRのハイブリッド抽出
- **Tesseract.js v5 エンジン**: 坂道グループのシリアル仕様（英大文字・数字・ハイフン）に特化したホワイトリスト抽出。
- **Canvas画像前処理パイプライン**: ガイド枠クロップ、グレースケール化、コントラスト強調、Otsuベースの適応的白黒二値化処理により、家庭の照明や斜め撮影でも高精度に認識。
- **jsQR リアルタイム検知**: 券面に印刷されているQRコードをフレームごとに自動検知（約0.1秒で即時取得）。
- **アルバム写真対応**: スマホで撮影済みの高解像度写真からも読み取り可能。

### 2. ⚡ 連続スキャン（まとめ打ち）モード
- 大量のCDを開封しながらテンポよく登録できる専用モード。
- スイッチをONにすると、確認モーダルを挟まずに「読み取り成功 → チャイム音 & バイブレーション → 自動ストック」を次々と実行。
- 二重スキャン時は**重複警告アラート**が発動し、同じコードの重複登録を確実にブロック。

### 3. 🎯 誤読ワンタップ置換
- OCRで誤認しやすい文字（`O ↔ 0`, `I ↔ 1`, `B ↔ 8`）をボタン1つで瞬時に相互置換。
- メモ（応募枠・部数・メンバー名など）も併せて記録可能。

### 4. 💿 作品（シングル・アルバム）＆ 応募サイト管理
- **作品ごとの専用応募URL登録**: シングルやアルバムごとに異なる応募特設サイト（fortune meets等）を自由に登録・ワンタップ切り替え。
- **📸 券面からのスマート自動抽出**: 券面の写真を撮影または選択するだけで、**上部黒字部分から作品名**、**右下QRコードから応募サイトURL**を自動検出して一瞬で登録完了。
- **最新タイトル標準プリセット**: 18thシングル『イチャイチャ虫』の公式応募サイト（`https://ticket.fortunemeets.app/hinatazaka46/18th`）を初期搭載。

### 5. 🚀 応募サイト自動登録アシスタント（スマホ対応）
- **📱 ワンタップ・ブックマークレット**:
  - 応募サイト（forTUNE meets / 特設サイト）を開いた状態で実行すると、画面下に日向坂46空色の**スマートフローティングバー**が出現。
  - シリアル入力欄を自動検出・代入（React等の仮想DOM対応）し、**「ワンタップ送信」** または **「全自動連続登録（1.5秒待機）」** を実行可能。
  - iPhone (Safari) および Android (Chrome) の図解セットアップガイドを内蔵。
- **⚡ タブ復帰連動シーケンサー（ゼロ設定）**:
  - スクリプト登録不要。SoraScanから1件目をコピーして応募サイトを開き、応募完了後に**SoraScanの画面に戻るだけ（タブフォーカス復帰を自動検知）で前のシリアルを自動で「応募済」にし、次のシリアルを自動コピー**。
- **🧪 動作検証用 模擬応募サイト（`mock-apply.html`）**:
  - CDの応募期間外や手元にシリアルがない時でも、forTUNE meets風のリアルな入力フォームで自動登録・連続登録の挙動を安全に100%テスト可能。

### 6. 📋 シリアル管理・応募アシスト
- **ワンタップ応募サイト直行 ＆ シリアル自動コピー**: 各シリアルカードから作品専用の応募サイトを直接開きつつ、シリアルを自動でクリップボードにコピー。
- **作品別未応募一括コピー**: 選択したシングル・アルバムの未使用シリアルだけをまとめて一括コピー。
- **Excel対応 CSVエクスポート**: 作品名・応募サイトURL付きのUTF-8 BOM付きCSVを出力。
- **JSONバックアップ & 復元**: 作品データとシリアルデータをまるごとエクスポート/インポート可能。

### 7. 🎫 模擬シリアル券シミュレーター
- 実物券面デザイン（上部黒帯ヘッダー・本文URL・シリアル枠＆QRコード）を完全再現した模擬券を動的生成。手元にCDがなくても解析精度やスマート登録フローをいつでも体験可能。

## 🚀 起動方法

### 前提条件
- Node.js（v18以上推奨）または任意の静的Webサーバー

### ローカルサーバーの起動

リポジトリ直下で以下のいずれかのコマンドを実行します：

```bash
# 方法1: npx serve を使用（推奨）
npx -y serve . -l 5173

# 方法2: Python を使用
python -m http.server 5173
```

ブラウザで以下のURLを開きます：
👉 **http://localhost:5173/**

## 📱 スマートフォンでの利用（PWAインストール）

PCと同じWi-Fiに接続している場合、スマートフォンのブラウザから直接アクセスしてアプリ化できます。

1. PCのIPアドレスを確認（例: `192.168.1.100`）
2. スマホのブラウザで `http://<PCのIPアドレス>:5173/` にアクセス
3. **Android (Chrome)**: メニュー（︙） → **「ホーム画面に追加」** または **「アプリをインストール」**
4. **iOS (Safari)**: 共有ボタン（↑） → **「ホーム画面に追加」**

ホーム画面の空色アイコンから起動すると、アドレスバーのない全画面ネイティブアプリとして動作します。

## 🔒 セキュリティとプライバシー

- **完全クライアントサイド動作（サーバーレス）**: 
  カメラで撮影した画像や抽出されたシリアルナンバーは、一切外部サーバーへ送信・保存されません。すべてお使いの端末内（ブラウザの `localStorage`）で安全に処理・保持されます。
- **Gemini AI オプション（BYOK方式）**: 
  設定画面からGemini APIキーを設定した場合でも、キーは端末内の `localStorage` にのみ保存され、Googleの公式APIエンドポイントへの直接通信時のみ使用されます。
- **安全なURL遷移**: 
  応募サイト直行機能は `https://` / `http://` プロトコルの正規URLのみを許可し、悪意あるスクリプトリンク（XSS）の実行を防止しています。
- **データ消失への対策**: 
  ブラウザの履歴消去等による消失を防ぐため、定期的に設定画面から「バックアップ書き出し（JSON）」または「CSVエクスポート」を行うことを推奨します。
