# SoraScan 操作マニュアル & 活用ガイド ☀️

日向坂46のCD封入スペシャル抽選応募シリアルナンバーを快適に登録・応募するための公式操作マニュアルです。

---

## 🎯 おすすめの利用シナリオ

### シナリオA: CDを1〜3枚だけ手動で応募したいとき
1. **「スキャン」タブ** を開きます。
2. ガイド枠の中にCD封入券のシリアルナンバーまたはQRコードを合わせます。
3. **「シリアルを撮影・読み取る (OCR)」** ボタンを押します（QRコードの場合はかざすだけで自動検知します）。
4. 表示されたモーダルでシリアル番号を確認し、盤種（Type-A等）を選択して **「保存して一覧へ」** を押します。
5. **「シリアル一覧」タブ** で **「コピー」** ボタンを押し、公式応募サイトへ貼り付けて応募します。
6. 応募が終わったらカード右側の **チェックマークボタン** を押して「応募済」にしておきます。

---

### シナリオB: CDを大量（10枚〜100枚以上）開封して「まとめ打ち」したいとき（推奨！）
1. **「連続スキャン（まとめ打ち）」のスイッチをON** にします。
2. カメラを机の上のCD券面に向けます。
3. 券面にQRコードがある場合は、**次々とカメラにかざすだけ** で「ピピッ♪」と音が鳴り、確認なしで自動的にリストに蓄積されます。
4. QRコードがない券面の場合は、ガイド枠に合わせて **「シリアルを撮影・読み取る (OCR)」** をテンポよく押していきます。
5. もし同じ券を二度スキャンしてしまっても、**「⚠️ 重複: ○○ は既に登録済みです」** と警告が出て二重登録を防ぎます。
6. 開封が終わったら **「シリアル一覧」タブ** を開きます。
7. **「未応募を一括コピー」** ボタンを押せば、全シリアルが改行区切りでコピーされます。
8. **「CSV保存」** ボタンを押せば、Excelで一覧管理できるCSVファイルがダウンロードされます。

## 💡 OCR読み取りのコツ

- **照明の反射を避ける**:
  - 部屋の蛍光灯がシリアル券の文字部分に直接反射して白飛びすると認識率が下がります。少し斜めに傾けるか、スマホの影にならない角度で撮影してください。
- **ガイド枠に近づける**:
  - シリアル文字が枠の幅の70〜90%程度を占めるくらい近づけると、文字のドットがくっきり写り、認識率が格段に向上します。
- **暗い場所ではライトを点灯**:
  - 画面右上の **⚡（稲妻アイコン）** を押すと、スマートフォンのライト（トーチ）が点灯します。
- **写真アルバムからの読み取り**:
  - 手ブレしてしまう場合は、スマホの標準カメラアプリで高画質に撮影しておき、**「アルバム写真から選択」** から読み込むと確実です。

## 🛠️ 便利機能一覧

| 機能 | 説明 |
| :--- | :--- |
| **誤読ワンタップ置換** | モーダル内の「O → 0」「I → 1」「B → 8」ボタンを押すだけで、OCRの類似文字を一発で修正できます。 |
| **ステータス切り替え** | シリアルカードの丸アイコンを押すと「未応募」⇄「応募済」が切り替わり、応募済みは取り消し線が入ります。 |
| **検索・フィルター** | シリアルコード、盤種（Type-A等）、メモ欄の文字列で即座に絞り込み検索ができます。 |
| **バックアップ (JSON)** | 右上の歯車アイコン →「バックアップ書き出し」で全データをファイル保存可能。スマホの機種変更時も「復元」で戻せます。 |
| **模擬券テスト** | 手元にCDがない時でも、「模擬券テスト」タブからテスト用シリアル券を自動生成して動作確認ができます。 |
