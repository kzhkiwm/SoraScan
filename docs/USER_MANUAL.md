# SoraScan 操作マニュアル & 活用ガイド ☀️

日向坂46のCD封入スペシャル抽選応募シリアルナンバーを快適に登録・応募するための公式操作マニュアルです。

---

## 🎯 おすすめの利用シナリオ

### シナリオA: CDを1〜3枚だけ手動で応募したいとき
1. **「スキャン」タブ** を開きます。
2. ガイド枠の中にCD封入券のシリアルナンバーまたはQRコードを合わせます。
3. **「シリアルを撮影・読み取る (OCR)」** ボタンを押します（QRコードの場合はかざすだけで自動検知します）。
4. 表示されたモーダルでシリアル番号を確認し、必要に応じてメモ等を入力して **「保存して一覧へ」** を押します（盤種の選択は不要です）。
5. **「シリアル一覧」タブ** で **「コピー」** ボタンを押し、公式応募サイトへ貼り付けて応募します。
6. 応募が終わったらカード右側の **チェックマークボタン** を押して「応募済」にしておきます。

---

### シナリオB: CDを大量（10枚〜100枚以上）開封して「まとめ打ち」したいとき（推奨！）
1. **「連続スキャン（まとめ打ち）」のスイッチをON** にします。
2. カメラを机の上のCD券面に向けます。
3. 券面にQRコードがある場合は、**次々とカメラにかざすだけ** で「ピピッ♪」と音が鳴り、確認なしで自動的にリストに蓄積されます。
4. QRコードがない券面の場合は、ガイド枠に合わせて **「シリアルを撮影・読み取る (OCR)」** をテンポよく押していきます。
5. もし同じ券を二度スキャンしてしまっても、**「⚠️ 重複: ○○ は既に登録済みです」** と警告が出て二重登録を防ぎます。
6. 開封が終わったら **「シリアル一覧」タブ** を開きます。
7. **「未応募を一括コピー」** ボタンを押せば、全シリアルが改行区切りでコピーされます。
8. **「CSV保存」** ボタンを押せば、Excelで一覧管理できるCSVファイルがダウンロードされます。

---

### シナリオC: 机に並べた複数枚の券を【写真・カメラから一括OCR】したいとき（超おすすめ！NEW!）
1. 机の上にCD封入券を10枚〜20枚ほど綺麗に並べます（2列5行など）。
2. **「シリアル一覧」タブ**（またはスキャン画面）で **「📥 シリアル一括登録」** または **「机に並べて一括撮影・OCR登録」** を押します。
3. 一括登録モーダル内の **「📸 カメラで撮影」** を押します（保存済み写真がある場合は **「🖼️ 写真を選択」**）。
4. スマホの背面高画質カメラが起動するので、並べた券全体が画面に収まるように真上から撮影します。
5. **Gemini 3.5 Flash-Lite** が画像内のすべての応募券を高速解析し、10〜20件のシリアルコードを一度にテキストエリアへ改行区切りで自動展開します。
6. リアルタイム解析サマリー（有効件数、新規件数、重複スキップ件数）とプレビューを確認し、**「一括登録を実行」** を押すだけで全件の登録が完了します！

---

### シナリオD: 外部ツールやPCメモから【シリアル一括登録】したいとき（NEW!）
1. バーコードリーダーや外部アプリ、テキストエディタ等でシリアル一覧をコピーします。
2. **「シリアル一覧」タブ** の **「📥 シリアル一括登録」** ボタンを押します。
3. **「貼付」** ボタンを押してテキストエリアに貼り付けます（複数スペース区切り、改行区切り、カンマ区切りに自動対応）。
4. 対象作品の末尾2文字（例: 18thなら `TN`）と合致する14桁英数字コードのみが自動抽出され、入力内重複や登録済み重複が事前判定されます。
5. **「一括登録を実行」** を押して一発保存します。

## 💡 OCR読み取りのコツ

- **並べた一括撮影のコツ**:
  - 券同士が重ならないように少し間隔をあけて平らに並べてください。
  - スマホの影が文字の上に落ちないよう、斜め上や明るい照明の下でピントを合わせて撮影してください。
  - Gemini APIキー（無料）を設定しておくと、認識率が格段に向上し、10〜20枚の写真でも瞬時に全件検出できます。
- **照明の反射を避ける**:
  - 部屋の蛍光灯がシリアル券の文字部分に直接反射して白飛びすると認識率が下がります。少し斜めに傾けるか、スマホの影にならない角度で撮影してください。
- **ガイド枠に近づける（1枚撮影時）**:
  - シリアル文字が枠の幅の70〜90%程度を占めるくらい近づけると、文字のドットがくっきり写り、認識率が格段に向上します。
- **暗い場所ではライトを点灯**:
  - 画面右上の **⚡（稲妻アイコン）** を押すと、スマートフォンのライト（トーチ）が点灯します。

## 🛠️ 便利機能一覧

| 機能 | 説明 |
| :--- | :--- |
| **初期表示「シリアル一覧」** | アプリ起動時にシリアル残数や登録済みリストを即座に確認できます。不要なカメラ起動や電力消費を防ぎます。 |
| **写真・カメラから一括OCR** | 机に並べた10〜20枚の券をスマホカメラで撮影するだけで、Gemini 3.5 Flash-Liteが全シリアルを一括自動抽出。 |
| **シリアルナンバー一括登録** | 複数スペースや改行区切りのテキストから、対象作品の末尾ルールに合致する有効コードのみを自動抽出して登録。 |
| **末尾2文字ヒント & 自動誤読補正** | 同じアルバムのシリアル末尾2文字（例: 18thなら「TN」）を記憶し、OCRで「M」や「I」に誤読された場合も自動で正しい末尾に補正します。 |
| **誤読ワンタップ置換** | モーダル内の「O → 0」「I → 1」「B → 8」「S → 3」ボタンを押すだけで、OCRの類似文字を一発で修正できます。 |
| **ステータス切り替え** | シリアルカードの丸アイコンを押すと「未応募」⇄「応募済」が切り替わり、応募済みは取り消し線が入ります。 |
| **検索・フィルター** | シリアルコードやメモ欄の文字列、作品名で即座に絞り込み検索ができます。 |
| **バックアップ (JSON)** | 右上の歯車アイコン →「バックアップ書き出し」で全データをファイル保存可能。スマホの機種変更時も「復元」で戻せます。 |
| **模擬券テスト** | 手元にCDがない時でも、「模擬券テスト」タブからテスト用シリアル券を自動生成して動作確認ができます。 |
